🍎 Desperdício de Alimentos na Escola

Este projeto tem como objetivo conscientizar os alunos sobre o desperdício de alimentos no ambiente escolar, mostrando a importância de evitar jogar comida fora e adotar hábitos mais sustentáveis.

Por meio deste site, buscamos apresentar informações, dicas e soluções para reduzir o desperdício de alimentos, incentivando pequenas atitudes que podem gerar grandes mudanças.

🎯 Objetivos

- Conscientizar sobre o desperdício de alimentos.
- Incentivar o consumo consciente.
- Reduzir o descarte de comida na escola.
- Promover atitudes sustentáveis.
